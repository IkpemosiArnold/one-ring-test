One ring test

My own published eval, plus a twin with six planted errors. Each lab reviews both copies. Flags on the clean copy count against it.

The twin. The clean copy is the Evaluation section of the Selects README.

    One flag per line: sentence, then class. Classes: numbers, overclaim, selection, prereg.

    • A catch needs the right sentence and the right class. Right sentence, wrong class is counted apart and earns nothing.
    • Each copy gets a separate run. A catch counts only if the same flag is absent on the clean copy, so flagging everything scores zero.
    • Precision counts flags on both copies. Recall is catches out of six. A pasted review is scored on the twin only.
    • Plain code runs three rules with no model, written knowing the key, so they show what a rule can see: counts that should add up, "a of b" against "about 1 in k", and an interval that holds the null next to a claim of an effect.
    • What this skips: real reviews are free text, and matching them to a sentence and class is the hard part. The clean copy is assumed error-free.
